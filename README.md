## 📂 Proyectos

### 🐾 Sistema de Gestión Veterinaria

Sistema de escritorio desarrollado en Java Swing y conectado a MySQL.

Permite gestionar:

- Dueños
- Mascotas
- Historial clínico
- Búsqueda global

Sistema de Gestión de Cafetería

Sistema backend basado en una arquitectura de microservicios.

Permite administrar:

- Usuarios
- Empleados
- Productos
- Inventario
- Ventas
- Reportes

Los servicios se comunican mediante APIs REST utilizando OpenFeign.

Sistema de Gestión de Pacientes

Aplicación frontend desarrollada con React y Vite para la gestión y agenda de pacientes.

El proyecto funciona sin conexión a un backend.
